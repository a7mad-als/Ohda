# عهدة · Ohda

منصة كويتية للوساطة في الدفع تحمي البائع والمشتري في صفقات المستعمل.
المشتري يدفع عبر Tap أو Stripe، والمبلغ يبقى محفوظ في «العهدة» لين يستلم الغرض ويتأكد منه، وبعدها ينصرف للبائع.

- الموقع: https://ohdakw.vercel.app
- الفيديو التعريفي: https://ohdakw.vercel.app/video/ohda-explainer.mp4

## المزايا
- صفقة جديدة برابط أو رمز أو باركود للمشتري
- تسليم حضوري (موافقة الطرفين من الجوال) أو توصيل مع مدة فحص
- مراحل الصفقة واضحة وبطاقة «وين راحت الفلوس؟»
- نزاعات مع «حَكَم عهدة» يطلع توصية مسببة يعتمدها الأدمن
- لوحة إدارة، وتطبيق ويب (PWA) يتثبت على الجوال

## التقنيات
React + Vite + TypeScript · Express API · Supabase (Auth, Postgres, Storage) · Tap و Stripe · Vercel
